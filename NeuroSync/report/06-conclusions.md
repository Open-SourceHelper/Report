
### Conclusiones y recomendaciones

#### Conclusión 1

Durante el Sprint 2 se logró avanzar en la implementación de los ocho Bounded Contexts de Kinemo, estableciendo una estructura modular que facilita la separación de responsabilidades y la evolución progresiva del sistema.

#### Conclusión 2

La implementación mediante Angular y TypeScript permitió desarrollar componentes de interfaz, modelos de dominio y servicios organizados según las responsabilidades de cada módulo, proporcionando una base para posteriores integraciones.

#### Conclusión 3

La utilización de JSON Server permitió verificar operaciones HTTP de consulta y registro durante el desarrollo, aunque la aplicación todavía requiere validación con los servicios definitivos y una infraestructura de backend integrada.

#### Conclusión 4

El uso de GitHub, ramas independientes y commits facilitó el trabajo colaborativo del equipo. Sin embargo, los conflictos encontrados durante los procesos de integración demostraron la importancia de mantener criterios compartidos para modificar archivos comunes.

#### Conclusión 5

Los avances del Sprint 2 permitieron consolidar una primera versión integrada a nivel de código. Para las siguientes iteraciones será necesario profundizar en las pruebas funcionales, la comunicación entre Bounded Contexts, la autenticación y el despliegue verificable de la aplicación.

#### Recomendaciones

Se recomienda implementar pruebas automatizadas, mejorar la coordinación de los contratos de datos entre módulos y mantener una estrategia de integración continua que permita detectar problemas antes de incorporar cambios a la rama principal.

Asimismo, se recomienda completar la documentación técnica de los servicios definitivos y verificar los criterios de aceptación de cada User Story.
